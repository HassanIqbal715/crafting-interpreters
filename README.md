# Crafting Interpreters
This repository contains exercises, code and notes for the book crafting interpreters.

# What is crafting interpreters?
- It is a beginner friendly book by Robert Nystorm in which they teach the core concepts of compilers and interprets.
- The main goal of the book is to build a programming language called "Lox".
- The first step of building is taught in Java to understand the concepts and build a working code.
- The second step is to optimize it as much as possible using C.
